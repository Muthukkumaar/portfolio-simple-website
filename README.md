# 🚀 My Personal Portfolio

Welcome to the repository for my personal portfolio website! This project features a clean, two-page layout designed using **HTML5** and **CSS3** to showcase who I am and provide an easy way to get in touch.

---

## 🛠️ Built With

*   **HTML5** – For structuring the web pages.
*   **CSS3** – For styling and layout design.

---

## 📄 Pages Included

1.  **Home Page:** Serves as the main landing page, introducing who I am, my background, and my work.
2.  **Contact Page:** Features an interactive contact form allowing visitors to send messages and connect with me.
